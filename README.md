# Itqan Codes Portfolio

A responsive portfolio site for Akinjobi Abdurrahman Olanrewaju, freelance web developer. The site uses plain HTML, CSS, and JavaScript; it does not need a build step or package installation.

## Files

- `index.html` — portfolio, projects, skills, experience, FAQs, and contact information.
- `resume.html` — résumé page with print styling for saving as a PDF.

## Preview

Open `index.html` in a browser, or serve this folder with a local static server. In VS Code, you can use the Live Server extension and choose **Open with Live Server**.

The site loads Google Fonts and some portfolio imagery from external hosts, so those resources need an internet connection.

## Résumé PDF

Open `resume.html` and select **Download PDF**. In the print dialog, choose **Save as PDF**.

## Before publishing

- Replace `https://github.com/YOUR-USERNAME` in `index.html` with the correct GitHub profile URL.
- Confirm the résumé, email, phone, project, and social links are current.
- Upload both HTML files together so the résumé link can resolve to `resume.html`.

The contact form opens a prefilled message in the visitor's default email app; it does not submit to a server.
